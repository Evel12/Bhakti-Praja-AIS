Pengujian Beban Grafana k6

Eksekusi k6 berlangsung lokal dan metrik dikirim ke Grafana Cloud. Beban dinaikkan selama 10 detik, dipertahankan 30 detik, lalu diturunkan 5 detik. Akun dan token berbeda digunakan per pengguna virtual. Run k6 selesai sebelum pengujian browser dimulai. Ambang sementara adalah p95 kurang dari 2.000 ms, p99 kurang dari 5.000 ms, dan tingkat kegagalan HTTP/aplikasi serta HTTP 429 kurang dari 1 persen.

Core AIS menguji perjalanan baca admin pada dashboard, siswa, kelas, jadwal, registrasi dan program keahlian. Finance menguji ringkasan, daftar/detail tagihan, daftar/detail pembayaran atau laporan admin serta unduhan bukti PNG kecil. Finance memakai kombinasi admin, siswa dan wali; jumlah tiap peran dicatat di JSON.

Batas Interpretasi

Hasil berlaku untuk skenario dan lingkungan yang dicatat. Pengujian beban merupakan baseline lokal berdurasi singkat, bukan kapasitas produksi atau uji ketahanan jangka panjang. Tidak ada login massal, transaksi bank nyata, payment gateway, pengiriman pengingat, inferensi AI atau perubahan assessment. Alur browser memakai UI dan pemeriksaan API secara gabungan; pemeriksaan negatif 403/404/409/422 yang diharapkan tidak termasuk kegagalan pada beban k6 baca normal. WebDriver tidak mengumpulkan seluruh exception JavaScript dan event HTTP 5xx; hanya respons API dan keadaan UI yang tercantum yang diperiksa. Lihat JSON untuk pemeriksaan individual dan temuan lengkap.

Jika satu tahap gagal, tahap sesudahnya pada modul tersebut tidak dianggap teruji. Hasil lulus pada perangkat lain tidak membatalkan temuan. Setiap PNG disimpan dalam resolusi aslinya dan memiliki SHA-256 pada evidence-manifest.json.
